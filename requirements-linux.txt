# Linux equivalent of requirements.txt. Same package versions confirmed to
# resolve identically on Linux (verified live via WSL2/Ubuntu 24.04, see
# install-linux.sh's header comment for the full feasibility investigation).
#
# What's DIFFERENT from requirements.txt, and why:
# - pywebview needs PyGObject + pycairo here too -- its Linux backend is
#   GTK + WebKit2GTK, which PyGObject binds to. These aren't optional the
#   way the CUDA packages are; without them pywebview has no GUI backend
#   to use at all on Linux. install-linux.sh installs the SYSTEM packages
#   (libgirepository-2.0-dev, libcairo2-dev, gir1.2-webkit2-4.1) these pip
#   packages need to build/run against -- pip alone can't provide those.
# - No nvidia-*-cu12 block. CUDA-via-WSL2 GPU passthrough is untested by
#   this project as of the initial Linux-support pass -- stt.py's
#   load_whisper() already tries cuda then falls back to cpu regardless,
#   so this isn't a hard requirement either way. Add the same nvidia-*-cu12
#   lines from requirements.txt here if/when GPU accel on Linux is
#   actually verified working; Linux's wheels use standard RPATH-based
#   linking, not the Windows DLL-search-order workaround stt.py has to do.
# - keyboard is still listed (voice_test.py's push-to-talk CLI fallback
#   works on Linux too), but its global-hotkey hook needs either root or
#   membership in the `input` group on Linux -- not needed at all for
#   assistant_app.py, which is VAD-driven, not push-to-talk.

numpy==2.5.2
sounddevice==0.5.6
keyboard==0.13.5          # push-to-talk in voice_test.py only -- needs root or the `input` group on Linux
faster-whisper==1.2.1
ctranslate2==4.8.1        # faster-whisper's backend -- pinned together, version-sensitive
piper-tts==1.7.0
onnxruntime==1.29.0       # CPU only -- used by both Piper and vad.py's SileroVAD
pywebview==6.2.1
PyGObject==3.58.0         # pywebview's Linux GUI backend (GTK bindings) -- needs libgirepository-2.0-dev to build
pycairo==1.29.1           # PyGObject's own dependency
pystray==0.19.5           # system tray icon -- verified on Windows only, see below
Pillow==12.2.0            # tray icon image generation

# pystray's Linux backends need an actual system tray protocol available
# (AppIndicator3/ayatana-appindicator, or a desktop environment that still
# supports the legacy freedesktop systray spec) -- install-linux.sh doesn't
# provision gir1.2-appindicator3-0.1 (or the ayatana equivalent), and this
# hasn't been verified against a real Linux desktop tray at all. Harmless
# either way: assistant_app.py wraps tray icon setup in a try/except and
# logs a one-line warning instead of failing to start if no backend is
# available, so this is a nice-to-have here, not a hard requirement like
# PyGObject/pycairo above.

# --- Optional: GPU-accelerated STT on AMD/Intel GPUs (NVIDIA already gets
# GPU accel above, via CUDA/faster-whisper) -- NOT installed by this file or
# install-linux.sh, since it needs a from-source build, not a plain pip
# install. CTranslate2 (faster-whisper's engine) only supports NVIDIA in its
# prebuilt wheels -- confirmed via its own hardware-support docs -- so AMD/
# Intel GPUs get zero acceleration through the packages above, full stop.
# whisper.cpp's Vulkan backend is vendor-neutral and stt.py already knows
# how to use it if present (see stt.py's module docstring + the fallback
# order in load_whisper()) -- verified live against a real Intel Arc Pro
# B70: genuine GPU engagement, correct transcription, ~1s for an 11s clip.
#
# To enable, after the system packages above are installed, also install:
#   sudo apt-get install -y build-essential cmake libvulkan-dev glslc \
#       spirv-headers spirv-tools glslang-dev glslang-tools
#   GGML_VULKAN=1 pip install git+https://github.com/absadiki/pywhispercpp
# Silently skipped by load_whisper() if not installed or no Vulkan device
# is found -- falls through to CPU either way, not a hard requirement.
